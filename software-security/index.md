When studying my Software Security course in university, we had a sequence of laborations with hands-on exercises for common types of vulnerabilities found in software. The laborations were based on the ones provided by the [SEED Project](https://seedsecuritylabs.org/) - specifically, we were using those associated with the Ubuntu 16.04-based lab environment, which no longer seems to be the current version anymore.

This is an index of the reports I wrote for each laboration we did in the course, which I now have published here on my website since I think they ended up being quite good pieces of writing.
